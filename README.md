# Squaremap Hider

This is a simple paper addon to [Squaremap](https://modrinth.com/plugin/squaremap) that allows a better way to hide players.

## Permissions

| Permnode                     | default | description                                                                                           |
|------------------------------|---------|-------------------------------------------------------------------------------------------------------|
| `squaremaphider.always_show` | false   | Always shows the player, bypassing all checks. **This is superious to `squaremaphider.always_hide`!** |
| `squaremaphider.always_hide` | false   | Always hides the player, bypassing all checks.                                                        |
| `squaremaphider.reload`      | op      | Allows the player to reload the configuration file.                                                   |
